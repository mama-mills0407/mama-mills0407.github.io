# Mom Life Picks

A free, mobile-friendly static mom blog designed for Amazon affiliate content.

This site is hosted on GitHub Pages at: **https://mama-mills0407.github.io**

## What's Included

- **index.html** - Homepage with featured picks and blog posts
- **about.html** - About the blog and mission
- **contact.html** - Contact page
- **affiliate-disclosure.html** - Amazon Associates disclosure
- **privacy-policy.html** - Privacy policy
- **style.css** - Responsive design styles

## Quick Tips for Content Updates

1. **Add new pages**: Create HTML files with the same header/footer structure
2. **Update links**: Links use relative paths (e.g., `about.html`, `posts/example.html`)
3. **Affiliate links**: Replace `[ADD AMAZON SPECIAL LINK]` placeholders with your Amazon Special Links from Associates Central
4. **Custom CSS**: Modify `style.css` to change colors, fonts, or layout
